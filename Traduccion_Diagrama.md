# Traducción del Diagrama de Flujo de Canva

## Menú y Navegación
* **Home** -> Home
* **Menú** -> Menu
* **Todos** -> All
* **Ramen** -> Ramen
* **Sushi** -> Sushi
* **Entradas** -> Starters (o Appetizers)
* **Postres** -> Desserts
* **Options** -> Options

## Carrito y Proceso
* **Añadir** -> Add
* **Carrito** -> Cart
* **Nombre** -> Name
* **Cantidad** -> Quantity
* **Total** -> Total
* **Proceder al pago** -> Proceed to checkout (o Proceed to pay)

## Recibo y Pago
* **Recibo** -> Receipt
* **Nombre del producto** -> Product name
* **Cantidad y cifra correspondiente** -> Quantity and amount
* **Precio total** -> Total price
* **X** -> X (Close)
* **Salir** -> Exit (o Close)
* **Pagar** -> Pay

*Nota: Para ver el diagrama interactivo de manera visual en formato de código, puedes utilizar herramientas online como Mermaid Live Editor.*
